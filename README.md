# ConnectX 🚀

ConnectX is a modern, real-time web chat application featuring instant messaging, voice recording capabilities, user management, group messaging, and customizable visual themes.

## 🌟 Key Features

- 💬 **Real-time Messaging**: Powered by Socket.IO for instantaneous message delivery and typing status notifications.
- 🎙️ **Voice Messages**: Integrated MediaRecorder API support for recording and sharing audio messages directly within chat.
- 👥 **User & Group Management**: Add contacts, create group chats, view online status, and switch/manage user profiles.
- 🎨 **Theme Customization**: Customizable color palettes, pre-built presets, and visual styling.
- 🔔 **Interactive UI**: Toast notifications, rich media rendering, message reactions, and clean modals.

## 📁 Repository Structure

```
ConnectX/
├── backend/    # Node.js, Express, Socket.IO & MongoDB backend API
└── frontend/   # React + Vite frontend SPA with Tailwind CSS / CSS styling
```

## 🛠️ Quick Start

### 1. Backend Setup

```bash
cd backend
npm install
npm run dev
```

### 2. Frontend Setup

```bash
cd frontend
npm install
npm run dev
```
